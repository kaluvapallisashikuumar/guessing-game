# 🎯 Guessing Game

A simple and interactive **Number Guessing Game** built using **HTML, CSS, and JavaScript**.

The game generates a random number between **1 and 100**. The user enters a number and clicks the **Check** button. The game provides feedback based on the user's guess.

## 🌐 Live Demo

👉 **[View Guessing Game](https://guessing-game-nine-mu.vercel.app/)**

## 🚀 Features

* 🎲 Generates a random number between 1 and 100
* 🔢 Allows the user to enter a number and check the guess
* ⬆️ Displays **"Too High! Try Again."** when the guess is greater than the random number
* ⬇️ Displays **"Too Low! Try Again."** when the guess is less than the random number
* 🎉 Displays a success message when the correct number is guessed
* ⚠️ Handles invalid input
* 📱 Responsive layout
* 🎨 Custom styling with CSS
* 🧩 Uses Bootstrap for responsive layout and UI components

## 🎮 How It Works

1. The game generates a random number between **1 and 100**.
2. Enter your guessed number in the input field.
3. Click the **Check** button.
4. The game compares your guess with the randomly generated number.
5. You will receive one of the following messages:

   * **Too High! Try Again.**
   * **Too Low! Try Again.**
   * **Congratulations! You got it right.**
6. Continue guessing until you find the correct number.
